## 👨‍💻 About Me

I'm a **Software Quality Assurance Engineer** who enjoys making sure software works the way people expect it to — on every browser, every device, and under load.

I work across the full testing spectrum: writing and executing manual test cases, building **UI automation with Selenium and Playwright**, automating **Android apps with Appium**, and running **performance tests with Apache JMeter**.

**What I do:**

- Manual & Functional Testing
- Cross-Browser Testing (Chrome, Firefox, Edge)
- Web UI Automation — Selenium WebDriver & Playwright (Python)
- Test Frameworks — Pytest & Page Object Model (POM)
- Mobile Application Testing — Appium & Android Studio
- API & Performance Testing — Apache JMeter
- Test Case Design & Bug Reporting
- QA Documentation

### 🎯 Open To

- QA Engineer / Junior QA roles
- QA Automation opportunities
- Manual, Mobile & Performance testing roles
- Software testing internships
